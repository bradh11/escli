# Security policy

escli handles your Elasticsearch API keys, so security is very important to
me. 🔒

## Supported versions

I fix security issues in the latest release only. Make sure you are using the
latest version:

```console
$ escli version
```

## Reporting a vulnerability

If you think you found a security issue, please **don't** open a public issue.

Instead, report it privately through
[GitHub's private vulnerability reporting](https://github.com/bradh11/escli/security/advisories/new).

Include:

* The escli version (`escli version`) and your platform.
* What the issue is, and what an attacker could do with it.
* The steps to reproduce it.

> [!WARNING]
> Never include a real API key in a report. Revoke any key that you think was
> exposed.

I will reply as soon as I can, and I will credit you in the fix, unless you
would rather stay anonymous.

## Thanks

Thank you for helping keep escli and its users safe. 🙏
